# HelloMate downloads

Official binary-only distribution for HelloMate Android Beta.

Public Beta status: not published.

No APK is currently available. A release will be listed here only after signing,
source provenance, public HTTPS messaging and installation checks pass.

## Release verification

Each approved release will include the APK, version, supported Android version and
CPU architecture, SHA-256 checksum, source commit, signer fingerprint and known
limitations. Download APK files directly from Releases; no GitHub login is needed
for public assets. Compare the downloaded SHA-256 with its published checksum.

This repository contains no proprietary source, private credentials, signing keys
or user data. Development APKs are not official Public Beta releases.
